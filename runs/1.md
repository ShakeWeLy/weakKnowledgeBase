## 目录与启动

- `weakKnowledgeBase/backend/`：FastAPI + SQLAlchemy + SQLite，结构参照 photo-show（`core/models`、`internal/db`、`routers`），并补上 `schemas/`、`repositories/`、`services/`。Router 只做参数声明和转发。
- `weakKnowledgeBase/frontend/`：React 19 + TS + Vite + Tailwind 4 + Zustand，版本和主题变量与 record-app 一致。

```bash
# 前端（在 frontend/ 下执行）
npm run dev        # http://localhost:5173，/api 代理到 8020
```

## 主要设计

- **md 为源，增量同步**：按内容哈希判断是否变化，文件消失时软删除，不硬删数据。解析规则版本号混入哈希，规则变化时旧条目自动重新索引。
- **全文检索**：SQLite FTS5 trigram，支持中文子串匹配并高亮片段；少于 3 个字符的关键词回退到 LIKE。Milvus 语义检索尚未接入。
- **筛选状态放在 URL**：分类、类型、标签、排序、分页都可以刷新、前进后退、分享。Zustand 只存每页条数这类界面偏好，避免双向同步的竞态问题。
- **关联**：手动创建，标签推荐只做展示，不自动写入。
